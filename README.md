# RestAssured
Rest Assured is a Java-based library used for API automation testing. It helps testers send HTTP requests, validate responses, and automate checks for RESTful web services in a simple, readable way using a BDD-style syntax like given(), when(), and then().

Why testers use it:
- It simplifies API test automation in Java.
- It supports common HTTP methods like GET, POST, PUT, DELETE, and PATCH.
- It allows validation of JSON and XML responses.
- It integrates well with TestNG, JUnit, Maven, Gradle, and CI/CD pipelines.
